Central de Integração com Qualquer PDV (API REST / Webhook)

Conecte o SmartMarket ao seu software de caixa atual (Bematech, Elgin, Totvs, PDV próprio em Python/Node) para automatizar a baixa de estoque em tempo real.

1. Endpoint da API de Baixa Automática

Seu PDV externo deve enviar uma requisição POST para o sistema com o JSON abaixo ao fechar um cupom:

{
  "caixa": "04",
  "cupom": "10492",
  "itens": [
    { "barcode": "7891000123456", "quantidade": 2 }
  ]
}

2. Script Local em Python para Sincronizar com PDVs Locais

Para PDVs que salvam em banco local (MySQL / SQLite / TXT), utilize este script para atualizar o ERP:

import requests, sqlite3

def sincronizar_vendas():
    conn = sqlite3.connect('pdv_local.db')
    cursor = conn.cursor()
    cursor.execute("SELECT barcode, qtd FROM vendas_pendentes")
    for barcode, qtd in cursor.fetchall():
        # Envia requisição para atualizar estoque
        requests.post('https://smartmarket.enterprise/api/baixa', json={"barcode": barcode, "qtd": qtd})
    conn.commit()
Sincronização automática ativa via LocalStorage.
